🚦 Road Accident Analysis Dashboard
📌 Project Overview

This project is an interactive Road Accident Analysis Dashboard developed using Microsoft Power BI. The dashboard provides detailed insights into road accident trends, casualty analysis, vehicle involvement, road conditions, and accident severity.

The main objective of this project is to transform raw accident data into meaningful business insights that help in identifying accident patterns and improving road safety decisions.

📊 Dashboard Highlights
Total Accidents Analysis
Total Casualties Tracking
Fatal, Serious, and Slight Casualty Breakdown
Vehicle Type Analysis
Road Surface & Weather Condition Insights
Urban vs Rural Accident Distribution
Day-wise and Month-wise Accident Trends
Interactive Filters and Dynamic Visualizations
